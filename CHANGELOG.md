# История изменений

## [Не выпущено]

### Добавлено

- Новый интерфейс Flutter из HTML-прототипа: палитра, векторные логотип и иконки, локальные шрифты, адаптивная навигация, плавные переходы с уменьшением движения. Убраны знак пламени в боковой панели и техническое имя в заголовке Windows.
- Готовая оригинальная сцена дерева Lua через MCP 0.7.0: фоны, портреты, дуги, рамки и иконки; масштабирование, поиск, подписи, выбор пути и возврат узлов. Кеш ресурсов отделён по ревизиям компонентов.
- Настоящие показатели, выбор основного умения, просмотр предметов и групп камней, формы текущих условий, видимые предупреждения и отметка устаревшего отчёта.
- Библиотека XML: создание, поиск, переименование, копия, сохранение и восстановление. Интеграционный сценарий Flutter с настоящим Lua.

### Исправлено

- После Release-сборки отладочный запуск Windows выбирает DLL движка Debug напрямую из соответствующего каталога SDK. Проверка CI сверяет обе DLL и предотвращает повтор ошибки `Can't load AOT data`.

- Управление состоянием через `flutter_bloc` и Cubit, неизменяемые снимки состояния, records для связанных значений и pattern matching для проверки ответов Lua.
- Проверка когнитивной сложности собственного Dart через закреплённый `treesitter_cyclomatic_complexity`; предел функции — 10 с учётом вложенных замыканий.
- Расчёты Lua на Linux x64 и macOS arm64 через MCP 0.4.0; отдельная проверенная загрузка нативных библиотек.

- CI для Windows x64, Linux x64 и macOS Apple Silicon; установщики `.exe`, `.run`, `.dmg`.
- Публикация по стабильному тегу после проверок; описание из этого файла и `SHA256SUMS`. Опубликованные файлы не заменяются повторным запуском.
- Проверка обновлений приложения, возобновляемая загрузка и обязательная проверка SHA-256.
- Настройка автоматической загрузки; установка только по кнопке «Перезапустить и обновить».
- Сохранение сборки и черновика XML перед обновлением. Отдельные каталоги приложения, пользовательских данных и компонентов.
- Проверка запуска новой версии и восстановление предыдущей при отсутствии подтверждения.

## [0.1.0] - 2026-11-05

- Первая рабочая основа Flutter: установка отдельных компонентов PoB/MCP, проверка совместимости через настоящий Lua, импорт и экспорт XML, создание и расчёт сборки.
- HTML-прототип, логотип, SVG-иконки, локальные шрифты и сайт GitHub Pages.
- Эта версия служит исходной точкой истории; публичные установщики до настройки CI не выпускались.
