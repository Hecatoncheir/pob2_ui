# История изменений

## [Не выпущено]

## [1.0.4] - 2026-11-25

- После назначения или снятия пассива Мастерская показывает обновлённые
  показатели сразу после сохранения XML. Полная геометрия обновляется в фоне
  с проверкой ревизии, пока прежнее дерево остаётся видно.
- На вкладке дерева возвращены полупрозрачные панели с размытым фоном.
- В комплект входит `pob2_engine v0.0.18`. Полная сцена дерева и подсветка
  узлов быстрее передаются в приложение.

## [1.0.3] - 2026-11-25

- В комплект входит стабильный `pob2_engine v0.0.16`. Предпросмотр поддержки
  показывает DPS выбранного умения до и после правки в черновике группы.


- Рабочие копии, отчёты и отрисовка подключены к комплектному
  `pob2_engine` через сгенерированный Dart gRPC API.
- Раздел «PoB2Engine» показывает подключение, версии движка и данных,
  запускает doctor и управляет обновлением и откатом данных PoB.
- В карточке данных объяснено назначение локального моста. Источник данных
  и журнал профиля раскрываются так же, как группы показателей в Мастерской.
- На схеме и в подсветке маршрутов скрыты служебные переходы к стартовым
  областям. Связи для назначения пассивов сохранены.
- Установка и работа PoB II используют комплектный Go-движок и исходный Lua PoB.

## [1.0.0] - 2026-11-24

- Начата линия `1.x.x` PoB II со штатной мастерской на `pob2_engine` и расчётами оригинального Lua PoB.
- Добавлены выбор общей сессии Go, обнаружение/автозапуск через дочерний `connect`, аренда приложения и поток gRPC с восстановлением пропущенных ревизий.
- Установленное приложение открывает записи библиотеки в постоянных сессиях. Название, ревизии и расчёт доступны также через CLI и MCP. При переименовании записи сохраняется её сессия.
- Штатное дерево общей сборки принимает правки пассивов, атрибутов, ветвей оружия, гнёзд и самоцветов, спецификации, класса и восхождения. Игровые правила по-прежнему выполняет исходный Lua.
- Дерево использует исходную геометрию, текстуры, подсказки и тепловую карту. Расчёт влияния показывает прогресс и поддерживает отмену.
- Штатные группы умений, экипировка, условия, заметки, Undo/Redo и этапы прокачки записываются через общие ревизии. Библиотека сохраняет обе версии при внешнем конфликте.
- Подключённый MCP передаёт команды в окно только после разрешения пользователя. Установщики 1.x включают бинарник общей сессии.
- Комплектный движок обслуживает редактор MCP и совместимые операции мастерской. Go устанавливает данные и LuaJIT, читает сборки из оригинального PoB и управляет его окном в Wine. Чистая установка PoB II работает без Python MCP.
- Закрытие окна при запуске дожидается чтения профиля и сохраняет загруженный черновик. Принятая команда выхода через MCP дожидается текущей операции.

## [0.12.0] - 2026-11-20

- Карточки экипировки, списки предметов и самоцветов, подсказки, примерка и список покупок показывают сохранившуюся базу, если имя уже повреждено и содержит последовательности `?` или символ замены. База переводится обычным игровым словарём; исходный XML и ответ Lua остаются без изменений.
- Исправлена терминология десяти языков: сборки персонажей, предметы, «Было / Стало», очки, отмена/повтор и основные характеристики. Редакторские исправления закреплены отдельно от машинного каталога и воспроизводятся генератором.
- Перевод поддерживает подтверждённые пары минимума/максимума добавленного урона. Порядок, знак и формат обоих чисел сохраняются; неоднозначные и неподтверждённые шаблоны остаются в оригинале.
- Добавлен сквозной сценарий названий предметов на десяти языках с настоящим Lua, снимками интерфейса и проверкой неизменности XML и характеристик. Проверка установщиков обновляет профиль v0.11.0.
- Описаны маркеры, подтверждение запуска, исключение неудачного кандидата и порядок будущей миграции протокола запускателя. Текущий формат сохранён.
- Через MCP доступны снимок элементов и PNG окна, нажатия, ввод и выделение текста, выбор, прокрутка, перетаскивание и сочетания клавиш. `close_dialog` закрывает любое верхнее окно, включая «Полный DPS»; форма сохраняется её кнопкой либо отменяется с `discard=true`. Авторизованное создание и открытие сборки через интерфейс сохраняет канал связи.
- Исправлена гонка файлового наблюдателя с сохранением заметок: проверка резервной копии использует актуальный XML после завершения собственных записей, сохраняя восстановление при внешнем изменении файла.
- Выпуск закрепляет PoB 0.23.1 и MCP 0.23.0. Физическая приёмка ограничена доступной Windows; Wayland и физические раскладки/Gatekeeper macOS проверяются отдельно от CI и в этом выпуске не заявляются пройденными. Подпись Windows и нотариализация macOS остаются отдельным этапом.

## [0.11.0] - 2026-11-19

- Импорт по ссылке поддерживает экспорты PoB с poe.ninja и прежнего poe2.ninja, включая raw-ссылки. Загрузка ограничена конкретным кодом сборки; расчёт выполняет исходный Lua.
- Для ссылок на профили и страницы персонажей poe.ninja диалог предлагает открыть сайт, получить Copy PoB code и вставить код. Прямой автоматический импорт профилей через внутренний API не используется.
- MCP `pob_editor_files/import_link` принимает ссылки экспорта poe.ninja. Для профиля он возвращает `imported: false`, `requires: pob_code`, исходную ссылку и следующее действие `import_code`, сохраняя текущую сборку и историю.
- Тесты проверяют распознавание адресов, работу диалога, импорт трёх классов с расчётом Lua, повторное открытие без сети и сохранность данных при отказе.
- Выпуск закрепляет PoB 0.23.1 и MCP 0.22.0.

## [0.10.3] - 2026-11-19

- Загрузчик Windows/Linux выбирает самую новую установленную стабильную версию по номеру, в том числе без `pending-version`. Устаревший маркер не понижает версию. Неудачный кандидат исключается из автоматического выбора, ручной откат сохраняется при следующем запуске.
- Установщики обновляют сам загрузчик. Windows также переводит старые ярлыки, включая закреплённые на панели задач, на основной загрузчик с сохранением аргументов.
- MCP 0.22.0 управляет PoB II через 42 инструмента без автоматизации экрана: состояние, подключение Lua, диалог MCP, библиотека, заметки, файлы, Undo/Redo, этапы прокачки, навигация, настройки, сохранение и завершение приложения.
- Обновление, откат и выбор установленного компонента выполняются фоном с проверкой текущего XML до переключения. Авторизованные операции MCP сохраняют канал; при отказе остаётся рабочая пара. Замена dev закреплённым выпуском требует явного параметра.
- Статус доступен при занятом приложении, чтение отчёта — при открытом диалоге. Изменения при незавершённом вводе в других диалогах защищены. Подсказки, сцена дерева, изображения и расчёты поддержек доступны через editor.
- Явный локальный флаг запуска `--mcp-editor` разрешает MCP для текущего запуска. Обычный запуск и перезапуск через MCP сохраняют выключенный по умолчанию доступ.
- Unix-права встроенного Python сохраняются независимо от ОС, на которой собираются архивы компонентов. После смены MCP обновляются команда подключения и поле `connectionCommand` статуса.
- Закрытие через MCP сохраняет данные, завершает Lua и выходит с кодом 0 без повторного вызова обработчика закрытия Windows. Сквозная проверка готового приложения измеряет фактический код завершения процесса; статус MCP сообщает версию, номер сборки и PID приложения.
- Выпуск закрепляет PoB 0.23.1 и MCP 0.22.0. Установщик Windows выпускается без подписи издателя. Пакет macOS подписывается ad hoc.

## [0.2.0] - 2026-11-14

- В разделе «Расчёты» можно выбрать часть и вариант основного умения, если PoB предоставляет такой выбор. Lua пересчитывает показатели, а выбор сохраняется в XML сборки.

- После потери ответа MCP кнопка «Подключить Lua» восстанавливает последнюю сохранённую сборку. Прерванная правка не отправляется повторно.
- В библиотеке план прокачки сохраняется при переименовании сборки и переносится в её копию.

## [0.1.0] - 2026-11-05

Первый публичный выпуск PoB II — отдельного интерфейса Flutter для Path of Building PoE2.
Все игровые данные, правила и расчёты получает исходный Lua PoB.

### Интерфейс

- Новый дизайн: логотип, векторные иконки, локальные Nunito, Nunito Sans и JetBrains Mono, плавные анимации с учётом системного уменьшения движения.
- Светлая тема и тёмная [Gruvbox](https://github.com/morhetz/gruvbox), сохранение темы, размера и положения окна.
- Масштаб всего интерфейса 75–200% с сохранением: настройка ползунком, Ctrl+− / Ctrl+=, сброс Ctrl+0. При нехватке высоты доступна прокрутка рабочей области.
- Десять языков интерфейса и доступных игровых текстов с сохранением выбора. Словари загружаются отдельно, проверяются SHA-256 и кешируются; неизвестные и неоднозначные строки остаются в оригинале. Добавлены шрифты CJK и Thai.
- Компоненты расположены двумя карточками рядом, на узком экране — друг под другом. Радиус текстовых кнопок — 12 px, у недавних сборок увеличены горизонтальные отступы.
- Кнопка новой сборки оформлена карточкой с отдельной иконкой плюса. Группы показателей выделены округлыми карточками, а закреплённый заголовок с эффектом frost glass пропускает прокручиваемый список под собой.

### Дерево и сборки

- Оригинальная сцена дерева PoB: фоны, портреты, дуги, рамки и иконки. Масштабирование, поиск по ID, оригинальному и переведённому названию, подсветка пути, назначение и возврат узлов через Lua.
- Стеклянные подсказки в цветах темы. Полезные изменения Lua выделены зелёным, ухудшения — терракотовым. Оценка эффекта не выводится из знака числа. Контраст основного текста — не ниже 7:1, цветных эффектов — 4,5:1 с учётом прозрачности.
- Поиск влияния узлов через оригинальный PowerBuilder: характеристика, расстояние, фильтр выбранных узлов, прогресс, отмена, тепловая карта и список с переходом к узлу. Изменение сборки сбрасывает отчёт; открытая панель выделяет свою иконку.
- Характеристики атрибутных узлов выбираются иконками и меняются без отключения узла или пути. Возврат очка доступен отдельно. Счётчики очков подписаны и различаются цветом с учётом темы: оружие I — красное или терракотовое, оружие II — зелёное.
- Клик по счётчикам пассивных очков, оружия I и оружия II переключает режим назначения узлов в исходном Lua. Назначения обоих наборов оружия сохраняются в XML; выбранный режим восстанавливается при загрузке сборки в текущем сеансе.
- Библиотека XML: создание, импорт, экспорт, поиск, переименование, копия и восстановление. Настоящие показатели и предупреждения Lua, выбор основного умения, просмотр предметов и камней, формы текущих условий.

### Установка и обновления

- Установщики Windows x64 (`.exe`), macOS Apple Silicon (`.dmg`) и Linux x64 (`.run`), публикация по стабильному тегу, changelog и SHA256SUMS.
- Отдельная установка PoB/MCP и проверка новой пары настоящим Lua перед активацией; сохранение рабочей пары и откат. Текущий протокол дерева рассчитан на MCP 0.9.1.
- Проверка обновлений приложения, возобновляемая загрузка и SHA-256, сохранение XML перед перезапуском, отдельные каталоги версий и возврат при неподтверждённом запуске.
- Исправлен выбор DLL движка Windows при переходе Release → Debug, вызывавший ошибку `Can't load AOT data`. Временные ответы GitHub 502/503/504 повторяются ограниченное число раз.

### Ограничения первого выпуска

- Для установки компонентов нужны Git и 64-разрядный Python 3.11+. Компоненты и игровые словари загружаются отдельно; после установки расчёты работают без сети.
- Установщики пока без подписи издателя; macOS использует ad hoc подпись.
- Редакторы предметов, камней и мастерств ещё не полностью заменяют оригинальный PoB. Перевод игровых описаний неполный; неоднозначные шаблоны сохраняют оригинал.
- Проверка расчёта PoB не означает проверку сборки в игре.
