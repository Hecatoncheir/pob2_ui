# Правила проекта

- Общение, документация и новые комментарии — на русском языке.
- Минимизируйте когнитивную сложность: небольшие методы, явные зависимости.
- Управление состоянием — `flutter_bloc`: Cubit/Bloc и неизменяемые состояния; не добавляйте ChangeNotifier.
- Records и pattern matching используйте для понятных типизированных результатов и проверки схем; не усложняйте простые условия.
- Проверяйте собственный Dart через `python tool/check_complexity.py`: когнитивная сложность функции не выше 10, включая вложенные замыкания. Порог не заменяет проверку читаемости.
- Flutter отвечает за интерфейс и локальное управление компонентами.
- Все игровые расчёты, правила и данные получает исходный Lua PoB. Не переносите формулы в Dart.
- Исходники PoB и MCP загружаются отдельно; не включайте их в Git этого проекта.
- Обновляйте компоненты в новом каталоге. Перед сменой активной пары запускайте настоящий Lua; при ошибке сохраняйте рабочую пару.
- Не выдавайте проверку расчёта PoB за проверку сборки в игре.
- Структура: `lib/domain` — модели, `lib/data` — процессы/сеть/хранение, `lib/ui` — состояние и представления.
- Проверки: `dart format --output=none --set-exit-if-changed lib test tool`, `flutter analyze`, `flutter test`, `flutter build windows --release`.
- Интеграционная проверка с загрузкой: `dart run tool/smoke.dart --install`. Она требует сети, Git и 64-битного Python 3.11+.
