# Языки интерфейса и игровых текстов

В настройках доступны русский, английский, французский, немецкий, испанский,
португальский (Бразилия), японский, корейский, тайский и традиционный китайский.
Выбор хранится отдельно в `language.json` профиля приложения и восстанавливается
до первого кадра. Переключение языка не перезапускает Lua и не меняет сборку.

## Сайт

На главной странице, в галерее и в разделе логотипа доступны русский, английский
и упрощённый китайский. Режим «Авто» выбирает первый поддерживаемый язык
из списка браузера или английский, если совпадений нет. Ручной выбор сохраняется
в браузере и применяется на всех трёх страницах. Без JavaScript доступна русская версия.

Переводы сайта хранятся в `docs/scripts/site-strings.js`, подписи и атрибуты
отмечаются в HTML через `data-i18n`. Скриншоты показываются в исходном виде.

## Интерфейс

Каталоги ARB находятся в `lib/l10n/arb`, генерация Flutter настроена в
`l10n.yaml`. `AppText` и `AppTooltip` переводят подписи через типизированный
`AppLocalizations`; параметры передаются строками, без пересчёта чисел.
Названия пользовательских сборок не переводятся.

`python tool/localize_ui.py` воспроизводит ARB и таблицу поиска из сохранённого
каталога без сети. Затем выполняются `flutter gen-l10n` и `dart format`.
Для добавления новых строк есть отдельный режим `--translate`: он отправляет
только публичные строки исходников интерфейса в Google Translate. XML, сборки,
игровые данные пользователя и содержимое профиля туда не передаются.
Новые машинные переводы требуют редакторской проверки; русские исходные
подписи и основные игровые термины заданы явно.

## Игровые данные

Используется выгрузка реальных игровых строк проекта
[PathOfExile_Translated](https://github.com/gw1108/PathOfExile_Translated/tree/0b5e587d69b433cfe277f5689876951fd1beff47).
Зафиксирована ревизия `0b5e587d69b433cfe277f5689876951fd1beff47`: в текущей
ветке этого источника остался только английский PoE2. Автор описывает
многоязычную выгрузку как данные клиента `4.5.4.3`. Она не гарантирует полноту
для каждой последующей версии PoB.

Права на игровые тексты и термины принадлежат Grinding Gear Games; инструмент
источника распространяется по MIT. Приложение не связано с GGG.
Полные игровые словари не включаются в Git или установщик оболочки.

При первом выборе языка загружаются английский и выбранный JSON. Размеры и
SHA-256 закреплены в `lib/data/game_locale_catalog.dart`. Файлы сохраняются
в `translations/<ревизия>/` профиля; повторное использование возможно без сети.
Разбор и построение словаря выполняются в изоляте. До завершения загрузки и
при ошибке доступны исходные строки; в настройках есть повторная загрузка.

Переводятся названия узлов, доступные описания, камни, предметы и классы.
Поиск дерева находит и оригинальное, и переведённое название, а также ID.
Список влияния узлов и фокусировка сохраняют оригинальные идентификаторы Lua.

Одинаковые английские строки с разными переводами считаются неоднозначными.
Для описаний дерева приоритет имеет каталог `stat_translations/passive_skill`.
Числовой шаблон применяется только при одном аргументе: его исходный знак и
значение копируются буквально. Шаблоны с несколькими `#`, неизвестные строки
и неподтверждённые соответствия остаются на исходном языке. Формулы,
идентификаторы, XML и исходные ответы MCP не переводятся.

## Шрифты и проверка

Основные шрифты — Nunito, Nunito Sans и JetBrains Mono. Для отсутствующих
глифов включены локальные Noto CJK и Noto Thai под SIL Open Font License:

- [Noto CJK](https://github.com/notofonts/noto-cjk/tree/f8d157532fbfaeda587e826d4cd5b21a49186f7c),
  `Sans/OTF/Japanese/NotoSansCJKjp-Regular.otf`;
  SHA-256 `68a3fc98800b2a27b371f2fb79991daf3633bd89309d4ffaa6946fd587f375b5`.
- [Noto Thai](https://github.com/google/fonts/tree/eb20e9cf19d97cf579fa3867d729d4222d6c59e1/ofl/notosansthai),
  `NotoSansThai[wdth,wght].ttf`;
  SHA-256 `5a1c559bb539583c8a1fd99d1c5b9491e5e14478c9cd2bd0970d5c3096cc9ef8`.

Лицензии находятся рядом с файлами в `docs/assets/fonts` и входят в поставку.

`flutter test` проверяет каталоги десяти языков, настройки, запоздавшие ответы
и сохранение чисел в подсказке. `dart run tool/check_languages.dart` загружает
и проверяет все закреплённые словари; необязательный первый аргумент задаёт
профиль кеша. Интеграционный сценарий с настоящим Lua проверяет поиск на
русском, японский интерфейс и неизменность показателей/XML при переключении.
