# Приёмка v0.9.0

Приёмка выполняется автоматизированно через тесты и CI по явному решению владельца от 19 ноября 2026 года. Это заменяет ручную приёмку этапа 09-05. Новая ручная проверка физических экранов, системного масштаба Windows и раскладок macOS не заявляется: локальный Mac заблокирован (`loginwindow`), доступной интерактивной сессии Windows/Linux нет. VoiceOver исключён из объёма по прежнему решению владельца.

## Окружение

- Windows x64: GitHub Actions `windows-2022`, системные диалоги Win32.
- macOS arm64: локальный Mac и GitHub Actions `macos-15`, Impeller Metal.
- Linux x64: GitHub Actions `ubuntu-22.04`, GTK/X11 в отдельном Xvfb; Wayland отдельно не проверяется.
- Flutter 3.50.0; PoB v0.23.1 (`7d6f530cbdab20389ff8bc6ba97a37ac27f74e41`), MCP v0.21.0 (`d932e4b6b05934c906607c6558e841cc64580967`). Пара закреплена в `tool/components-lock.json`, исходники находятся вне репозитория.
- Каждый сценарий использует отдельный `POB2_UI_HOME`. Рабочий профиль пользователя и Docker не используются.

## Покрытие и пределы

| Проверка | Способ и результат |
| --- | --- |
| Показатели и стоимость путей | Контракт сначала проверен на macOS прямыми вызовами Lua: 12 сочетаний общего режима/I/II, активного оружия I/II и двух целей. [Эталоны](LUA-CONTRACT.md#сравнение-путей-для-наборов-оружия-iii). |
| Применение I/II | Постоянный сквозной тест сравнивает предпросмотр с независимой сессией исходного Lua, применяет A и B, проверяет одно действие Undo/Redo, XML, заметки и план прокачки. Исходные файлы и история предпросмотра сохраняются. |
| Потеря ответа MCP | Ответ импорта теряется после фактического изменения Lua. Последний сохранённый XML и история не меняются; переподключение восстанавливает рабочую сборку, повторного импорта правки нет. |
| Устаревший ответ | Смена режима после расчёта и активного оружия во время расчёта отклоняет применение старого результата. |
| Размер панели | Виджетные тесты: ширины 360/1280/1920 px, масштаб приложения 75/100/200%, обе цели и кнопки доступны прокруткой. Это проверка раскладки Flutter; системный масштаб Windows отдельно не измерялся. |
| Клавиатура | Поиск целей и Enter проходят через интерфейс сквозного теста. Сохраняются проверки сочетаний, переназначения команд и канала нативных XML-команд macOS. Физические Cmd+O/Cmd+S в двух раскладках заново не проверялись. |
| Нативные диалоги XML | `tool/check_native_xml.py` на Windows/Linux открывает настоящий диалог Ctrl+O, отменяет его, открывает XML I/II, сохраняет Ctrl+S по пути с кириллицей и пробелами и открывает файл повторно; распределения сверяются. Нативные диалоги macOS в текущей сессии недоступны. |
| Отказ записи | Существующие тесты файловой библиотеки, истории и выхода подтверждают сохранность последнего состояния, удержание несохранённого текста и повтор после устранения ошибки. |
| Перезапуск и обновление | Проверка установщиков запускает профиль v0.8.0 в старом и новом приложении, сверяет XML, заметки и отчёт без HTTP для обоих активных наборов оружия, проверяет очистку и откат компонентов. |
| Окно | Существующий автоматизированный сценарий Windows проверяет геометрию, разворачивание, возврат на доступный экран и сохранение перед закрытием; тесты настроек проверяют масштаб и ширину панели. |

Локально на macOS прошли `flutter analyze`, 256 тестов приложения (один платформенный пропуск), проверка сложности ≤10 и все пять сквозных сценариев путей за 7 мин 35 с, включая 12 сочетаний эталонной таблицы. Горячий перезапуск завершился без ошибок. Собраны Release-приложение и DMG `0.9.0+42`; `tool/check_installer.py --target macos-arm64 --build-check --components ... --previous ...` завершился с кодом 0. Подтверждены запуск, замена приложения, откат, очистка и восстановление профиля v0.8.0, оба активных набора оружия, XML и заметки без HTTP. Ревизия кандидата — `4aea234` (исправление повторного выбора цели — `0248616`).

На ревизии `a005892` сквозной набор путей прошёл на Windows x64, macOS arm64 и Linux x64: все 12 сочетаний эталонной таблицы, применение A/B, Undo/Redo, XML и восстановление MCP. Нативные диалоги Windows/Linux также прошли, включая отмену, кириллицу и пробелы в пути. [CI кандидата](https://github.com/Hecatoncheir/pob2_ui/actions/runs/44410321658). Полная матрица кандидата завершилась успешно на всех трёх ОС: форматирование, анализ, модульные и виджетные тесты, сложность ≤10, сайт, Release-сборки, установщики, Lua и все сквозные сценарии. Публикация и проверка опубликованных файлов будут записаны после релизного CI.

Windows выпускается без подписи издателя; macOS — с подписью ad hoc, без нотариального заверения Apple. Получение доверенных подписей ведётся отдельно в задаче [#21](https://github.com/Hecatoncheir/pob2_ui/issues/21).
