# Приёмка PoB II v0.12.0

Дата: 20 ноября 2026 года, по Москве. Кандидат: `0.12.0+48`.
Пара компонентов: PoB v0.23.1 (`7d6f530cbdab20389ff8bc6ba97a37ac27f74e41`),
MCP v0.23.0 (`1b3f61dc00016fe3bc86d889d6f4992302231d75`).

## 12-01 · Названия предметов

В исходной сборке со снимка пользователя имена редких предметов уже содержат
`?` в XML и в отчёте Lua; базы предметов сохранились. Дополнительный опыт с
кириллическим пользовательским именем подтвердил нормализацию исходным PoB:
`Item:Item` вызывает `sanitiseText`. Передача строки из Dart в процесс MCP
отдельно проверена как UTF-8. Это ограничение разбора PoB, а не отсутствие
кириллицы в шрифте или повреждённый русский словарь.

Интерфейс использует неповреждённое имя, а при его отсутствии — базу из Lua.
База проходит обычный игровой перевод. Если оба значения недоступны,
отображается `—`. XML, исходный ответ Lua и игровые характеристики не меняются.
Это распространяется на карточки экипировки, самоцветы, выбор сохранённого
предмета, заголовок описания/примерки и список покупок/сравнение этапов.

Проверки регрессии: [имена](../test/item_name_test.dart),
[карточка и подсказка](../test/item_name_widget_test.dart),
[реальный Lua и десять языков](../integration_test/item_names_test.dart).
В сквозном сценарии используются отдельный профиль и синтетические предметы,
без изменения сборок пользователя. На Windows сценарий прошёл: повреждённое
имя заменяется базой, `Tide Song` сохраняется, каждый язык оставляет прежние XML
и показатели. Снимки: `build/review/item-names-<язык>-<ОС>.png` в артефактах CI.

Редакторские исправления закреплены в [ui_reviewed.json](../lib/l10n/ui_reviewed.json)
и воспроизводятся [генератором](../tool/localize_ui.py). Проверяются полнота
807 сообщений каждого языка, пустые строки и неизменность `{pN}`. Это
редакторская проверка перечисленных контекстов, без заявления о независимой
проверке каждого предложения носителями всех языков.

Порядок двух аргументов проверен для пар минимального/максимального добавленного
урона: исходный PoB задаёт `{0}`, `{1}`, закреплённые языковые записи сохраняют
тот же порядок. Разрешены только эти ID и форма `Adds # to # … Damage`.
Для остальных шаблонов и разных переводов одной строки остаётся оригинал.
`tool/check_languages.dart` проверяет все десять словарей с SHA-256 и сохранение
знака, дробного разделителя и порядка чисел; это не проверка формул игры.

## 12-03 · Интерфейс и обновление

Пользователь подтвердил доступность **только Windows и CI**. Физические
Wayland, macOS, Gatekeeper и русская/английская раскладки Cmd+O/Cmd+S
недоступны в этой сессии и не считаются пройденными. CI macOS и Linux
проверяет программные сценарии и установщики, Linux запускается под Xvfb/X11.
Системный масштаб Windows проверяется только при фактически доступной настройке;
сценарии масштаба интерфейса 75–200% не подменяют изменение системного DPI.

| Проверка | Windows локально | Windows/Linux/macOS в CI |
| --- | --- | --- |
| Имена предметов, десять языков, XML и Lua | Пройден сквозной сценарий; настоящее окно просмотрено | Ожидается кандидат |
| Ширины 360/1280/1920, длинные строки и масштаб интерфейса | Модульные/виджетные проверки | Матрица тестов кандидата |
| Нативные XML-диалоги, отмена и Unicode-путь | Интерактивная проверка остановлена физической Esc; не заявляется пройденной | Windows/Linux: нативный сценарий; macOS: программные каналы |
| Ошибка записи, сетевой отказ, восстановление XML и заметок | Проверки состояния и файлов | Сквозные сценарии и установщики |
| Обновление с v0.11.0, запуск без сети, откат | Ожидается готовый установщик | Ожидается кандидат |

## 12-05 · Полное управление интерфейсом через MCP

Требуются PoB II 0.12.0 и [MCP 0.23.0](https://github.com/Hecatoncheir/pob-poe2-mcp/releases/tag/v0.23.0).
[CI MCP](https://github.com/Hecatoncheir/pob-poe2-mcp/actions/runs/44615508785) прошёл:
транспорт, настоящий Lua Windows/Linux/macOS и мост открытого PoB под Wine.
Протокол описан в [MCP-EDITOR.md](MCP-EDITOR.md).

Виджетные проверки проходят: произвольный диалог, поле поверх поиска,
кириллический ввод, сохранение и явная отмена формы, отказ устаревшего снимка,
нажатия, перетаскивание, прокрутка, Shift + нажатие, F-клавиши и сочетания
с освобождением модификаторов, в том числе при ошибке жеста.
Сквозной Windows-сценарий с внешним процессом MCP и настоящим Lua создал сборку
через форму, сохранил канал и проверил настоящее окно «Полный DPS», его PNG
и закрытие командой `close_dialog` и клавишей Escape. Проверка повторена с
опубликованным архивом MCP 0.23.0 после проверки SHA-256 и запуска Lua.
Сценарий дополнен ширинами 1024 и 1280 px. В узком окне сначала открывается
«Показатели», затем вложенный «Полный DPS»; оба окна закрываются через MCP.
Размер PNG сверяется с координатами снимка. Локально оба варианта прошли.
Это устраняет ошибку теста, предполагавшего всегда видимую правую панель.
Снимки матрицы трёх ОС: `build/review/mcp-full-dps-<ширина>-<ОС>.png`.

Системные окна выбора файла не входят в снимок Flutter. Файловые операции
без этих окон доступны через `pob_editor_files` с явным путём. Доступ MCP
включается вручную и после перезапуска запрашивается снова.

## Проверки кандидата и выпуск

Локально прошли статический анализ, целевые проверки имён и переводов,
когнитивная сложность ≤10, Python-проверки, 11 проверок сайта и smoke на
закреплённой паре с `source: original-lua`. Сквозной сценарий имён прошёл
на Windows с десятью языками. Полный повторный прогон: 286 успешных тестов,
один пропуск. Повторный отказ проверки восстановления заметок выявил гонку
между снимком файлового наблюдателя и собственной записью библиотеки.
Теперь после очереди записи читается актуальный XML; отдельная регрессия
проверяет сохранность резервной копии при устаревшем снимке. Для очистки
временной папки на Windows используется общий помощник с повтором удаления.
Отладочное окно кандидата запущено в отдельном профиле, горячая перезагрузка
выполнена успешно. В настоящем окне подтверждены база шлема на русском и
исходное имя `Tide Song`; физические параметры ОС не менялись.

[CI исходного кандидата `8810947`](https://github.com/Hecatoncheir/pob2_ui/actions/runs/44608419811)
прошёл на трёх ОС: имена, десять языков, установщики и обновление с v0.11.0.
Расширенный [кандидат `d8c0a3a`](https://github.com/Hecatoncheir/pob2_ui/actions/runs/44621950464)
с MCP 0.23.0 прошёл установщики и проверку Lua, но сценарий «Полный DPS»
на Windows/macOS требовал адаптации к узкому окну. Исправленный сценарий
выполняется в обязательной релизной матрице перед публикацией.
В первом расширенном прогоне Linux не получил ответ при создании первой
сборки за 180 секунд; выпуск из него не публиковался. В повторном прогоне
тот же сценарий создания и завершения прошёл за 61 секунду. Источник
первой задержки не установлен; для повторных отказов добавлен вывод состояния
приложения при тайм-ауте, без изменения ограничения времени.
[Релизная матрица `07af976`](https://github.com/Hecatoncheir/pob2_ui/actions/runs/44631035078)
завершилась успешно на Windows x64, macOS arm64 и Linux x64.
[v0.12.0 опубликован](https://github.com/Hecatoncheir/pob2_ui/releases/tag/v0.12.0)
20 ноября 2026 года в 02:40 по Москве: три установщика и `SHA256SUMS`.

Успешный расчёт PoB не означает испытание сборки в игре. Windows пока выпускается
без подписи издателя, macOS — с подписью ad hoc, без нотариализации.
