# Снимки приёмки

`support-comparison-v0130.png` снят 20 ноября 2026 года на Windows в кандидате PoB II `0.13.0+50`. База на момент съёмки — `5c2e6d3` с рабочими изменениями v0.13.0, до фиксации кандидата.

Исходный PNG 1264×681 получен из `RenderRepaintBoundary` нативным сценарием `integration_test/editors_test.dart`. Сборка демонстрационная, создана тестом. Lua PoB v0.23.1 и MCP v0.24.1 сравнивают Chaos Attunement и Cold Attunement для Fireball с существующей поддержкой Controlled Destruction. Обе новые поддержки имеют уровень 1 и качество 0. В отдельной группе Ice Nova не хватает интеллекта; исходное предупреждение показано в результатах. В поиске оставлен точный ID, использованный тестом.

Сценарий подтвердил порядок результатов, сохранность XML и истории. Снимок не редактировался; личные сборки не использованы. Расчёт PoB не является проверкой в игре.
