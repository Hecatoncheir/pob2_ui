# Снимки работающего приложения

Сняты 6 ноября 2026 года на Windows в отдельном тестовом профиле. Это исходные PNG Flutter, без дорисовки интерфейса. Дерево, умения, предметы и показатели получены от настоящего Lua PoB, MCP 0.15.0. Исходный код интерфейса: `6f1d70b` / `fb0f4f8` (последняя ревизия меняет только прокрутку каталога в проверке).

- `tree-light`, `tree-dark`, `settings`, `components`: сценарий `integration_test/workspace_test.dart`.
- `skills`: отдельное работающее окно Flutter после сценария `integration_test/editors_test.dart`, снимок через Dart VM Service.
- `equipment`, `comparison`: сценарий `integration_test/equipment_test.dart`.
- `trade`: отдельное работающее окно Flutter, снимок через Dart VM Service.

Примерка и подготовка торгового поиска не входят в опубликованные установщики v0.1.4; в галерее они выделены отдельно. Остальные снимки показывают уже доступные возможности, но сняты в текущей рабочей ветке. Исходные изображения игровых объектов принадлежат Grinding Gear Games.
