# Снимки работающего приложения

Сняты 6 ноября 2026 года на Windows в отдельном тестовом профиле. Это исходные PNG Flutter, без дорисовки интерфейса. Дерево, умения, предметы и показатели получены от настоящего Lua PoB, MCP 0.15.0. Дерево, настройки, компоненты и умения сняты перед выпуском; экипировка, рынок и примерка пересняты в v0.1.6, ревизия `94be011`.

- `tree-light`, `tree-dark`, `settings`, `components`: сценарий `integration_test/workspace_test.dart`.
- `skills`: отдельное работающее окно Flutter после сценария `integration_test/editors_test.dart`, снимок через Dart VM Service.
- `equipment`, `comparison`: отдельное работающее окно Flutter после сценария `integration_test/equipment_test.dart`, снимок через Dart VM Service.
- `trade`: отдельное работающее окно Flutter, снимок через Dart VM Service.

Примерка и поиск на рынке доступны в опубликованном v0.1.6; в галерее они выделены как новые возможности. Остальные снимки показывают уже доступные возможности, снятые перед этим выпуском. Исходные изображения игровых объектов принадлежат Grinding Gear Games.
