# Снимки работающего приложения

Снимки сделаны 11 ноября 2026 года на Windows в PoB II v0.1.20, ревизия `8bc00aa`. Это исходные PNG Flutter из отдельных тестовых профилей. Игровые данные и показатели получены через PoB v0.23.1 и MCP v0.18.1.

- `tree-dark`, `node-power`, `components`: сценарий `integration_test/workspace_test.dart`.
- `skills`: сценарий `integration_test/editors_test.dart`.
- `equipment`, `comparison`, `trade`: сценарий `integration_test/equipment_test.dart`.
- `first-run`, `library`, `tree-light`, `settings`: отдельный локальный прогон той же ревизии. Для библиотеки использованы тестовые XML из сквозной проверки, а экран первого запуска снят с пустым профилем.

Снимки сценариев выпуска доступны в артефакте `ui-windows-x64`. [Проверки выпуска v0.1.20](https://github.com/Hecatoncheir/pob2_ui/actions/runs/42990332779)

Изображения игровых объектов принадлежат Grinding Gear Games.
