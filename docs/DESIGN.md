# PoB II · «Искра»

HTML/CSS/JS-прототип будущего интерфейса Flutter. Рабочее имя приложения сохранено: PoB II. «Искра» — название визуального направления.

## Просмотр

- `index.html` — одностраничный сайт; светлая и тёмная темы, окна с описанием.
- `prototype.html` — интерактивная мастерская.
- `brand.html` — логотип, палитра, типографика, SVG-иконки и иллюстрации.
- `assets/pob2-brand-kit.zip` — набор векторных ресурсов.

Страницы можно открыть непосредственно с диска. Для одинакового поведения хранилища и загрузок рекомендуется HTTP:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory docs
```

Откройте `http://127.0.0.1:4173/`. Сборка и установка зависимостей не требуются. Шрифты сохранены локально; для прототипа сеть не нужна. Ссылки на GitHub требуют подключения.

## Характер оформления

Молочная бумага, графитовая тушь, мягкие углы, строгие числа. Органичный силуэт пламени объединён с узлами дерева: идея становится сборкой. Пятно туши, камень и куб поддерживают мотив мастерской и алхимии. Иллюстрации изометрические, с чёрными гранями и резкой тенью; навигационные значки проще и читаются в малом размере. Референсы определяют настроение; исходные знаки и иллюстрации нарисованы заново в SVG.

## Интерфейс

Приоритет — ясность и удобство. Скриншот PoB использован для проверки доступности функций и примера значений. Основной экран строится вокруг текущего действия: большой редактор, пять разделов и компактная панель показателей. Подробности раскрываются по запросу.

Главные разделы приложения: «Мои сборки», «Мастерская», «Компоненты». В мастерской: «Дерево», «Предметы», «Умения», «Условия», «Расчёты». Название сборки можно изменить нажатием; класс, восхождение и уровень редактируются через одну кнопку под названием. Сохранение автоматическое, рядом доступны копия и импорт/экспорт.

Панель показателей остаётся рядом с редактором при переключении разделов. По умолчанию она показывает выбранное умение, DPS и четыре важных показателя. Можно закрепить от одного до шести характеристик. Урон, ресурсы, защиты, сопротивления, характеристики и передвижение доступны в раскрываемых группах; все группы есть в разделе «Расчёты». Нажатие на число открывает место для объяснения отчёта Lua. Произвольные полоски под числами удалены. Статус расчёта виден постоянно.

В дереве работают поиск, перемещение холста, масштаб, независимые основной и альтернативный варианты, отмена/повтор выбора узлов. Сравнение вариантов, набор оружия, версия дерева, пример подсветки силы узлов и сброс помещены в меню. Очки дерева, оружия и восхождения собраны в одну строку. Сброс требует подтверждения и доступен для отмены.

До 1250 px боковая навигация компактная, до 500 px — нижняя. До 1100 px панель показателей открывается отдельным слоем с кнопкой закрытия, фокусом внутри и заблокированным фоном. Основной редактор сохраняет доступную ширину. В приложении прокручиваются содержимое редактора и подробности показателей; сайт остаётся рассчитанным на один экран обычного настольного монитора.

Также доступны библиотека, поиск и сортировка сборок, создание персонажа, карточки предметов, группы умений, выбор умения и части для расчёта, условия, заметки, режим группы, сравнение сохранённых показателей и демонстрация установки компонентов. Режим группы пока сохраняет только флаг: каталог союзников и эффектов не подключён.

Данные хранятся под ключом `pob2-design-v1`. Старые записи дополняются настройками нового интерфейса без удаления заметок и узлов; пример с присланного скриншота добавляется в библиотеку. JSON версии 1 сохраняет оба варианта дерева, выбор умения, оружия, важные показатели, заметки и подготовленный XML. При недоступном хранилище можно продолжать в памяти и экспортировать файл.

### Границы демонстрации

В сборке Shattering Concoction показатели вручную перенесены с присланного скриншота: это сохранённый снимок, а не новый расчёт PoB. Остальные примеры вымышлены. Изменение узлов, условий или наборов не пересчитывает значения; интерфейс показывает ожидание Lua. Изменение класса, восхождения или уровня убирает прежний пример отчёта, чтобы не приписывать его новому персонажу. Неизвестные значения и отсутствующие части умения показываются прочерком.

Схема дерева иллюстративная, счётчики очков взяты из снимка и не связаны с узлами макета. Подсветка силы узлов — пример оформления. Камни поддержки и предметы сборки со скриншота не предполагаются: без исходных данных показано пустое состояние.

XML проверяется только на синтаксис и корневой элемент и сохраняется для будущей передачи Lua. Он не применяется к сборке. Экспортируется собственный JSON прототипа; настоящий импорт и экспорт PoB требуют движка. Демонстрация установки ничего не скачивает и не запускает. Образцы ошибок в окне состояния явно отделены от текущих уведомлений. Подключения к MCP/Lua нет.

### Проверки прототипа

```powershell
node --test tool/design_state_test.cjs
node --check docs/scripts/app.js
node --check docs/scripts/workspace-data.js
node --check docs/scripts/workspace.js
node --check docs/scripts/workspace-actions.js
```

Пять проверок данных охватывают перенос старых сохранений, JSON с обоими деревьями и ожидающим XML, очистку неизвестных полей, отклонение некорректных значений и пустой отчёт новой сборки. В Chrome проверены ширины 1366 и 390 px, поиск, отмена выбора узлов, доступность панели при смене разделов, сравнение, отклонение постороннего XML и открытие мобильной панели. Горизонтального переполнения и ошибок в консоли в этих сценариях не обнаружено.

## Движение

| Действие | Длительность | Характер |
| --- | --- | --- |
| Отклик кнопки, смена цвета | 180 мс | Без задержки действия |
| Появление панели, смена раздела | 380–420 мс | Смещение 18 px и прозрачность |
| Диалог | 380 мс | Смещение 20 px, масштаб 0,97 → 1 |
| Показатели и графические пути | 650–1400 мс | Однократное появление |
| Масштаб дерева | 550 мс | Плавное приближение |
| Иллюстрация на сайте | 9 с | Очень медленное колебание |

Основная кривая — `cubic-bezier(.22, 1, .36, 1)`. Анимации используют прозрачность и преобразования. Рисование пути и индикаторы ограничены небольшими элементами. Есть `prefers-reduced-motion` и переключатель анимаций в оформлении прототипа. На клавиатуре работают вкладки со стрелками, Home/End, узлы с Enter/пробелом, диалоги с Escape. Модальные окна используют нативный `dialog`.

## Перенос во Flutter

1. Вынести палитру, размеры, шрифты и длительности в тему. Подключить локальные TTF через `pubspec.yaml`, сохранить OFL-уведомления.
2. Представить боковую/нижнюю навигацию через общий выбранный раздел. Состояние сборки оставить в `lib/ui`, модели — в `lib/domain`, хранение и MCP — в `lib/data`.
3. Переносить небольшими виджетами: заголовок сборки, показатель, панель дерева, группа умений, предмет, компонент, диалог. Для переходов использовать `AnimatedSwitcher`, `FadeTransition`, `SlideTransition` и соответствующую кривую `Cubic(.22, 1, .36, 1)`.
4. Данные и действия подставлять через явные зависимости из `WorkshopCubit`. До реализации возможностей PoB показывать честное пустое состояние. Не включать демоданные в рабочие расчёты.
5. Реальные координаты дерева, классы, предметы, камни, совместимость, характеристики и предупреждения получать из оригинального Lua через MCP. Геометрия HTML-макета не является основой игрового дерева.
6. Анимации отключать через системный признак уменьшения движения. Не анимировать длительно каждый узел настоящего большого дерева. Узлы рисовать с отдельной обработкой выбора и масштабирования; обеспечить доступность управления.
7. Установку и откат связывать с существующим менеджером компонентов. Перед активацией новой пары обязательно запускать настоящий Lua, при ошибке сохранять прежнюю пару.

Никакие игровые формулы не переносятся в JavaScript или Dart. Проверка интерфейса и успешный расчёт PoB не означают проверки сборки в игре.

## GitHub Pages

Сайт: [hecatoncheir.github.io/pob2_ui](https://hecatoncheir.github.io/pob2_ui/). Настройка Pages — **GitHub Actions**. Workflow `.github/workflows/pages.yml` запускает проверки данных и синтаксиса JavaScript, затем публикует статический каталог `docs` при изменениях в `main` или ручном запуске. Публикация не требует npm, Jekyll или Flutter Web. Все локальные ссылки относительные и работают под `/pob2_ui/`.

Состояние конкретной публикации доступно в GitHub Actions. Кнопки скачивания приложения нет, поскольку готовый публичный установщик в рамках этой задачи не проверялся.

## Реализовано во Flutter 5 ноября 2026

Тема, локальные шрифты, векторные ресурсы и анимации перенесены. В боковой панели используется компактная надпись без знака пламени; в компактной навигации — значок II. Рабочий интерфейс получает настоящие данные Lua. Дерево воспроизводит готовую сцену оригинального `PassiveTreeView` с текстурами PoB, а не геометрию HTML-макета. Короткие переходы и масштабирование отключаются системным уменьшением движения. [Контракт, ограничения редакторов и проверки](LUA-CONTRACT.md). HTML остаётся самостоятельным макетом с демонстрационными данными.

Уточнение поведения дерева: никаких постоянных подписей. При наведении показываются сведения и расчётные изменения из Lua и оригинальная подсветка пути. Обычный клик назначает или возвращает узел; дополнительные свойства доступны по удержанию. Положение и размер окна сохраняются средствами платформы.
