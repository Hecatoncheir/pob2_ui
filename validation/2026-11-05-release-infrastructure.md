## Практические ограничения

Git и 64-битный Python 3.11+ пока остаются внешними требованиями. Linux — x64, macOS — Apple Silicon; другие архитектуры не заявлены. PNG через GDI/Direct3D остаётся возможностью Windows.

Подпись издателя Windows и Developer ID / нотариализация macOS не настроены. Подпись ad hoc в CI подтверждает целостность `.app`, но не издателя. Полная ручная приёмка на обычных системах, сетевые обрывы во время реального обновления и переход между двумя публичными версиями приложения остаются отдельными проверками. Автовозврат проверяет первый запуск оболочки; совместимость игровых компонентов проверяется отдельно через Lua.

Успешный расчёт PoB не означает испытание сборки в игре. Новые редакторы и новый Flutter-дизайн продолжают план v0.2.0/v0.3.0.
